`GET /api/v1/positions`、`GET /api/v1/positions/{id}`、`POST /api/v1/exchange/positions`

- `positions_list_returns_active_rows` — 多空持仓独立成行

## 三、集成测试

位置：`crates/trading-service/tests/e2e/`（in-process 真实 store/引擎 + `trading-sim`）、
`tests/blackbox/`（真实二进制 + REST）、各 crate 的 `tests/` 目录。
共 116 个集成用例（不含 ctp 特性）。

> 说明：E2E 使用模拟所（binance 永续合约语义），不连真实币安。

### 币安市价单

`order_lifecycle::o01_market_open_fills_and_creates_position`
市价开仓 → 模拟所成交 → 宿主仓位落库；`indeterminate_place_marks_order_unknown`
覆盖下单应答不确定 → UNKNOWN。

### 币安限价单

`order_lifecycle::o02_limit_open_stays_new_until_filled`
限价开仓挂单保持 NEW，触发成交后推进 FILLED。

### 币安回落止盈平仓

`risk_close::r07_profit_drawdown_take_profit`
ROI 达到峰值后回落超过阈值 → 触发绑定的风控平仓，并校验仓位/信号。

### 其他集成场景

- 条件开仓：本标的/跨标的价格、绑定仓位 ROI、关联仓位归零（`conditional_open`，4）
- 风控平仓：价格/ROI/限价/绝对量/跨标的/突破全平（`risk_close`，10）
- 重启恢复、规则链、优雅停机（`restart`、`harness_smoke`、`blackbox`）
- 交易所接口契约（`trading-exchange/tests/conformance/`，9）
- 持久化往返（`tests/persistence.rs`，3）
- 性质/不变量（proptest）：`trading-models/tests/properties.rs`（4）+
  `trading-service/tests/properties.rs`（6）

**执行**：

```bash
cargo test -p trading-service --test e2e
cargo test -p trading-service --test blackbox
cargo test -p trading-exchange --test conformance
cargo test -p trading-store --test crud --test concurrency --test persistence
```

## 附：测试支撑设施

- **`trading-sim`**：`SimLedger`（订单/持仓/余额/事件台账）+ `SimApi`（`ExchangeApi`/
  `AccountEventStream`）+ `SimVenue`（`VenueProvider`），可设标记价、杠杆、拒单、查询三态。
- **`trading_service::testkit`**：生产装配面的最小白名单（`app_with_accounts`、
  `assemble_app`、`AppState`、`RegistryFactory`、`admin_router`、`serve_south_ws` 等），
  生产与测试共用同一条装配路径。
- **各目标 support**：`tests/api/support.rs`（两套装配 + HTTP helper）、
  `tests/e2e/harness.rs`（TestApp/种仓/等待收敛）、`tests/blackbox/support.rs`
  （真实进程栈 + 串行锁）。
- **隔离**：每用例独立 `TempDir`、随机端口、合成 `account.csv`（7 列），不触网。
- **门禁**：`bash scripts/test-all.sh`（fmt → clippy → workspace → all-features → 覆盖率）；
  强制 `CARGO_BUILD_JOBS=2`、`--test-threads=2`，同一时刻只允许一个 cargo 进程。
